# 花蓮分院音控室

法鼓山花蓮分院音控室的互動工具，用來查接線、找設備、排除故障。

網址（開啟 GitHub Pages 後）：https://tallyc.github.io/ddm-hualien-av/

## 畫面

**簡易版**（首頁）：給值班義工，一次只問一步。
- 哪裡沒有聲音／哪裡沒有畫面：沿訊號路徑逐站問「有開機、線有接好嗎？」，找出可能出問題的設備
- 查設備：先選位置，再選設備

**高階版**（`advanced.html`）：給音控主責與維護者，有接線圖、完整設備清單、排障清單、簡報模式與 A4 列印。

兩版都能切換夜間模式、調整色相與彩度。

## 資料

| 檔案 | 內容 | 怎麼更新 |
| --- | --- | --- |
| `data/devices.json` | 影音設備清冊（總表） | 試算表下載成 .xlsx，執行 `python3 tools/build_devices.py 清冊.xlsx` |
| `data/system.json` | 沙盒上的設備、圖層、連線，以及簡易版的症狀選項（`symptoms`） | 直接編輯 |

`system.json` 的連線中，`"ok": true` 表示已確認，其餘是從沙盒截圖整理、待現場確認。
